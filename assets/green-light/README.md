- `lock`, `step-0`, `step-1`: Kenney [Impact Sounds](https://kenney.nl/assets/impact-sounds), `impactMetal_heavy_000`, `footstep_grass_000/001`.
- `rain`, `thunder`: WuxiaScrub, [Rain + Long Thunder](https://opengameart.org/content/rain-long-thunder), excerpts at 2–14s and 19–30s.
- `shot`: Joseph SARDIN, [Shot Beretta M12 9mm](https://bigsoundbank.com/coup-de-feu-de-beretta-m12-9-mm-s0437.html), trimmed and peak-limited for the fictional sentry.
