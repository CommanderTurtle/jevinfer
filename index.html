01 Set the stream

Plain text, username: message, optional [HH:MM:SS.mmm], or JSONL with user + message + timestamp (seconds/ISO) or at_ms. Up to 16 MiB. No account connection.

A burst occupies the end of each period. Original timestamps ignore rate and burst settings. Replay pauses when this page is hidden to avoid browser timer throttling; in-flight requests may finish.

02 Define the signal

Category definitions & extra questions

The category key is reserved. Extra questions share the same single-message request; their results appear in Inspect judgment and exports.

Uses the selected endpoint and protocol. Workers are HTTP concurrency, not model sequences. Raw arrivals never wait for a free worker; a slower endpoint makes the queue grow. Mean output delay includes queueing and in-order release. No actual bans or chat actions.
